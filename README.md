# The World in One Page — 23 November 2026

Entry for the make.fun bounty [news-image-20261123](https://make.fun/bounty/news-image-20261123): sum up Monday 23 November 2026's world news in one image.

`main.py` (pure Python 3.13 stdlib — no Pillow, no third-party code) draws a
newspaper front page with a hand-written 5×7 bitmap font and a hand-rolled
PNG encoder, and writes it to `/output/entry.png` (1024×1024, deterministic).

Stories covered: COP31 talks collapse in Turkiye · tankers burning in the
Strait of Hormuz · sea drones sink the Russian corvette Merkury off Benghazi ·
a Russian drone hits flats in Dymer, near Kyiv · Liverpool rout Manchester
United in Pochettino's debut · plus a ticker (Nepal PM meets Modi, South
Korea minister quits, Shuri Castle reopens, Lahore AQI 538, Cikande factory
fire).
